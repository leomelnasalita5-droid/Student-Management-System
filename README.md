Student Management System

Project Overview

A Java console-based Student Management System developed for a Data Structures and Algorithms (DSA) project.

Features

- Add Student
- View All Students
- Update Student Information
- Delete Student
- Search Student using Binary Search
- Sort Students by ID
- Sort Students by Name
- Sort Students by Grade
- Student Rankings
- Class Statistics
- View Student Count

Technologies Used

- Java
- Java Scanner
- Singly Linked List
- Binary Search
- Bubble Sort
- Arrays

Data Structures and Algorithms

- Singly Linked List: Stores student records dynamically.
- Binary Search: Searches student records using their ID.
- Bubble Sort: Sorts student records by ID, name, and grade.
- Array: Temporarily stores linked-list nodes for searching and ranking.

Target Users

Teachers, instructors, school administrators, and educational institutions.

How to Run

1. Download or clone this repository.
2. Open the Java file using your preferred Java IDE.
3. Compile and run "StudentManagementSystem.java".
4. Follow the menu options displayed in the console.
